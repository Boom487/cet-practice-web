# CET4/6 Online Practice Website
> 四六级在线练习网站 | Frontend + Data processing project

## Project Introduction
A lightweight web application for CET-4/CET-6 exercise and mock exam.
Developed for self-practice of college English test.
All data runs on browser client, no backend server required.

### Core Features
1. 📖 Question bank system, support question switch
2. ⏱️ Exam countdown, auto submit when timeout
3. ✅ Automatic answer checking & score statistics
4. ❌ Error question collection, save records via LocalStorage
5. 📱 Responsive layout, works on PC and mobile phone

## Tech Stack
- HTML / CSS / Vanilla JavaScript
- JSON for structured question bank
- LocalStorage for persistent data storage

## How to run
1. Clone this repo
2. Open index.html in browser directly
> No server needed.

## Project Highlights
- Structured question dataset, can import bulk exam questions
- User answer data analysis, collect wrong questions automatically
- Pure frontend implementation, easy to deploy on GitHub Pages
